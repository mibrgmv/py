## 1. Условие задачи

Решается дифференциальное уравнение первого порядка:

$$\frac{dy}{dx} = x^2 + x + 5y$$

с начальным условием:

$$y(0) = 0.4$$

на интервале $x \in [0; 1]$.

## 2. Численные методы решения дифференциальных уравнений

### 2.1. Метод Эйлера

Метод Эйлера является простейшим явным одношаговым методом численного интегрирования обыкновенных дифференциальных уравнений.

#### 2.1.1. Формулировка метода

Для дифференциального уравнения:

$$\frac{dy}{dx} = f(x,y)$$

с начальным условием $y(x_0) = y_0$ формула Эйлера имеет вид:

$$y_{n+1} = y_n + h \cdot f(x_n, y_n)$$

где:
* $h$ - шаг интегрирования
* $x_n = x_0 + n \cdot h$ - текущее значение независимой переменной
* $y_n$ - приближенное значение решения в точке $x_n$

#### 2.1.2. Пример реализации

Для конкретной задачи с правой частью $f(x,y) = x^2 + x + 5y$:

$$y_{n+1} = y_n + h \cdot (x_n^2 + x_n + 5y_n)$$

### 2.2. Метод Рунге-Кутты 4-го порядка

Метод Рунге-Кутты 4-го порядка обеспечивает более высокую точность по сравнению с методом Эйлера.

#### 2.2.1. Формулировка метода

Для того же дифференциального уравнения метод реализуется следующей системой:

$$\begin{cases}
k_1 = f(x_n, y_n) \\
k_2 = f(x_n + \frac{h}{2}, y_n + \frac{h}{2}k_1) \\
k_3 = f(x_n + \frac{h}{2}, y_n + \frac{h}{2}k_2) \\
k_4 = f(x_n + h, y_n + hk_3) \\
y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)
\end{cases}$$

где:
* $k_1$ - наклон в начале интервала
* $k_2$ и $k_3$ - наклоны в середине интервала
* $k_4$ - наклон в конце интервала

#### 2.2.2. Геометрическая интерпретация

Метод использует взвешенное среднее четырех различных оценок наклона для достижения более точного результата:
* $k_1$ - оценка наклона в начале интервала
* $k_2$ и $k_3$ - две оценки наклона в середине интервала
* $k_4$ - оценка наклона в конце интервала

#### 2.2.3. Пример реализации

Для нашей конкретной функции $f(x,y) = x^2 + x + 5y$ система принимает вид:

$$\begin{align}
k_1 &= x_n^2 + x_n + 5y_n \\
k_2 &= (x_n + \frac{h}{2})^2 + (x_n + \frac{h}{2}) + 5(y_n + \frac{h}{2}k_1) \\
k_3 &= (x_n + \frac{h}{2})^2 + (x_n + \frac{h}{2}) + 5(y_n + \frac{h}{2}k_2) \\
k_4 &= (x_n + h)^2 + (x_n + h) + 5(y_n + hk_3) \\
y_{n+1} &= y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)
\end{align}$$

## 3. Аналитические методы решения дифференциальных уравнений

### 3.1. Метод степенных рядов

#### 3.1.1. Общая схема метода

Для дифференциального уравнения:

$$\frac{dy}{dx} = f(x,y), \quad y(0) = y_0$$

Решение ищется в виде ряда Тейлора:

$$y(x) = \sum_{k=0}^{\infty} a_k x^k$$

Коэффициенты определяются последовательной дифференциацией:

$$a_k = \frac{y^{(k)}(0)}{k!}$$

#### 3.1.2. Пример реализации (n=4)

Для уравнения с $f(x,y) = x^2 + x + 5y$ и начальным условием $y(0) = 0.4$:

$$y(x) \approx \sum_{k=0}^{4} a_k x^k$$

Коэффициенты ряда:

$$\begin{cases}
a_0 = y(0) = 0.4 \\
a_1 = f(0, a_0) = 0^2 + 0 + 5 \cdot 0.4 = 2 \\
a_2 = \frac{1}{2!}\frac{d}{dx}(x^2 + x + 5y)|_{x=0} = \frac{1}{2}(2x + 1 + 5y')|_{x=0} = \frac{1 + 5 \cdot 2}{2} = \frac{11}{2} = 5.5 \\
a_3 = \frac{1}{3!}\frac{d^2}{dx^2}(x^2 + x + 5y)|_{x=0} = \frac{1}{6}(2 + 5y'')|_{x=0} = \frac{2 + 5 \cdot 11}{6} = \frac{57}{6} = 9.5 \\
a_4 = \frac{1}{4!}\frac{d^3}{dx^3}(x^2 + x + 5y)|_{x=0} = \frac{1}{24}(5y''')|_{x=0} = \frac{5 \cdot 57}{24} = \frac{285}{24} = 11.875
\end{cases}$$

Итоговое приближение:

$$y(x) \approx 0.4 + 2x + 5.5x^2 + 9.5x^3 + 11.875x^4$$

### 3.2. Метод последовательных приближений (Пикара)

#### 3.2.1. Теоретические основания

Метод основан на принципе сжимающих отображений. Решение строится как предел последовательности:

$$y_{n+1}(x) = y_0 + \int_{0}^{x} f(t, y_n(t))dt$$

#### 3.2.2. Алгоритм реализации (n=3)

Для того же уравнения:

$$\begin{align}
y_0(x) &= 0.4 \\
y_1(x) &= 0.4 + \int_{0}^{x} (t^2 + t + 5 \cdot 0.4)dt = 0.4 + 2x + \frac{x^3}{3} + \frac{x^2}{2} \\
y_2(x) &= 0.4 + \int_{0}^{x} (t^2 + t + 5y_1(t))dt \\
&= 0.4 + \int_{0}^{x} \left(t^2 + t + 5 \cdot \left(0.4 + 2t + \frac{t^3}{3} + \frac{t^2}{2}\right)\right)dt \\
&= 0.4 + \frac{x^3}{3} + \frac{x^2}{2} + 2x + 5 \cdot \left(0.4x + x^2 + \frac{x^4}{12} + \frac{x^3}{6}\right) \\
y_3(x) &= 0.4 + \int_{0}^{x} (t^2 + t + 5y_2(t))dt
\end{align}$$

Из-за сложности выражения для $y_3(x)$, вычисления производятся численно.

## 4. Теоретические оценки погрешностей

### 4.1. Метод Эйлера

Локальная погрешность на шаге:

$$\tau_n = \frac{h^2}{2}y''(\xi_n), \quad \xi_n \in [x_n, x_{n+1}]$$

Глобальная погрешность:

$$|y(x_n) - y_n| \leq \frac{Mh}{2L}(e^{L(x_n-x_0)} - 1)$$

где:
* $M = \max |y''(x)|$ (оценка)
* $L$ - константа Липшица для $f(x,y)$

Для наших данных:
* $L \approx 5$ (оценка по наибольшему коэффициенту при $y$)
* $M \approx 11$ (оценка по второй производной)

Для $h = 0.1$ теоретическая оценка:
$$|y(x_n) - y_n| \leq \frac{11 \cdot 0.1}{2 \cdot 5}(e^{5 \cdot 1} - 1) \approx 0.11 \cdot 147.4 \approx 16.2$$

### 4.2. Метод Рунге-Кутты 4-го порядка

Локальная погрешность:

$$\tau_n = \frac{h^5}{5!}y^{(5)}(\xi_n)$$

Глобальная погрешность:

$$|y(x_n) - y_n| \leq \frac{Ch^4}{L}(e^{L(x_n-x_0)} - 1)$$

где $C$ - константа метода.

Для $h = 0.1$:
$$|y(x_n) - y_n| \leq \frac{C \cdot 0.0001}{5}(e^{5 \cdot 1} - 1) \approx \frac{C \cdot 0.0001 \cdot 147.4}{5} \approx C \cdot 0.003$$

### 4.3. Метод степенных рядов

Погрешность усечения:

$$R_n(x) = \frac{y^{(n+1)}(\xi)}{(n+1)!}x^{n+1}, \quad \xi \in [0,x]$$

Для $n = 4$ при $x = 1$:

$$|R_4(1)| \leq \frac{M_5}{5!}$$

где $M_5 = \max |y^{(5)}(x)|$

Оценивая $M_5 \approx 500$:
$$|R_4(1)| \leq \frac{500}{120} \approx 4.2$$

### 4.4. Метод последовательных приближений (Пикара)

Оценка погрешности после $n$ итераций:

$$\|y_n - y\| \leq \frac{L^n}{(n+1)!}\|y_1 - y_0\|$$

Для $n = 3$ и $L \approx 5$:

$$\|y_3 - y\| \leq \frac{5^3}{4!}\|y_1 - y_0\| = \frac{125}{24}\|y_1 - y_0\| \approx 5.2 \cdot \|y_1 - y_0\|$$

## 7. Выводы

1. Для данного дифференциального уравнения метод Рунге-Кутты 4-го порядка оказался наиболее точным из рассмотренных методов, что соответствует теоретическим ожиданиям.

2. Метод Эйлера показал значительно бóльшую погрешность, которая существенно снижается при уменьшении шага интегрирования (с h=0.1 до h=0.05), что подтверждает первый порядок аппроксимации метода.

3. Аналитические методы:
   - Метод степенных рядов с n=4 показал хорошую точность в начале интервала, но его погрешность растет к концу интервала из-за ограниченного числа членов ряда.
   - Метод последовательных приближений с n=3 показал наибольшую погрешность, что объясняется недостаточным числом итераций для данной задачи.

4. Сравнение теоретических и практических погрешностей показывает, что для данного уравнения с быстро растущим решением реальные погрешности оказались выше теоретических оценок, что указывает на сложность задачи.

5. При увеличении точности требований к решению рекомендуется использовать метод Рунге-Кутты с достаточно малым шагом либо увеличивать число членов в методе степенных рядов или число итераций в методе последовательных приближений.
