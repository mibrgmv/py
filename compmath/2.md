## 1. Задание
Вычислить приближённо значение определённого интеграла с абсолютной погрешностью, не превышающей 10^-3 методами трапеций и парабол. Оценку погрешности выполнить практически и теоретически.

$$f(x) = e^x \cdot x^2, \quad a = 0, \quad b = 1$$

## 2. Метод трапеций
Формула составного метода трапеций:

$$T_N = \frac{h}{2}\left[f(x_0) + 2\sum_{i=1}^{N-1}f(x_i) + f(x_N)\right], \quad h = \frac{b - a}{N}$$

Теоретическая погрешность:

$$|R_T| \leq \frac{(b - a)^3}{12N^2} \cdot \max_{x\in[a,b]} |f''(x)|$$

Погрешность вычисляется по формуле:

$$R_n = -\frac{(b - a)}{12} \cdot h^2 \cdot f''(\xi), \quad \xi \in [a, b]$$

где $h = \frac{b-a}{n}$ - шаг разбиения.

Абсолютная погрешность ограничена:

$$|R_n| \leq \frac{(b - a)}{12} \cdot h^2 \cdot M_2$$

где $M_2 = \max_{x\in[a,b]} |f''(x)|$.

### Вычисление второй производной

Для функции $f(x) = e^x \cdot x^2$:

Первая производная:
$$f'(x) = e^x \cdot x^2 + 2x \cdot e^x = e^x \cdot x \cdot (x + 2)$$

Вторая производная:
$$f''(x) = e^x \cdot x^2 + e^x \cdot x \cdot (x + 2) + 2e^x \cdot (x + 1) = e^x(x^2 + 4x + 2)$$

В коде эта функция определена как:
```python
def second_derivative(x):
    return 6*x*np.exp(x) + 6*np.exp(x)
```

### Вычисление количества разбиений

Реализуем функцию для расчета необходимого количества разбиений:

```python
def calculate_n_for_trap(a, b, tolerance):
    M = np.max(np.abs(second_derivative(x)))
    n = math.ceil(math.sqrt(((b - a)**3 * M) / (12 * tolerance)))
    return n
```

Для заданной точности $\varepsilon = 10^{-3}$ получаем:
```
Для метода трапеций n=17
```

## 3. Метод парабол

Формула составного метода Симпсона:

$$S_N = \frac{h}{3}\left[f(x_0) + 4\sum_{i=1, \text{неч}}^{n-1}f(x_i) + 2\sum_{i=2, \text{чет}}^{n-2}f(x_i) + f(x_n)\right]$$

Теоретическая погрешность:

$$|R_S| \leq \frac{(b - a)^5}{180n^4} \cdot \max_{x\in[a,b]}|f^{(4)}(x)|$$

### Четвертая производная функции

Для функции $f(x) = e^x \cdot x^2$:

В коде четвертая производная определена как:
```python
def fourth_derivative(x):
    return 24*x*np.exp(x) + 96*np.exp(x) + 24*x**2*np.exp(x)
```

### Вывод формулы для $n$

Из условия $|R_S| \leq \varepsilon$ получаем:

$$\frac{(b - a)^5}{180n^4} \cdot M_4 \leq \varepsilon$$

$$n^4 \geq \frac{(b - a)^5 M_4}{180\varepsilon}$$

$$n \geq \left(\frac{(b - a)^5 M_4}{180\varepsilon}\right)^{1/4}$$

### Учёт чётности $n$

Метод Симпсона требует чётного $n$, поэтому окончательная формула:

```python
def calculate_n_for_simpson(a, b, tolerance):
    M = np.max(np.abs(fourth_derivative(x)))
    n = math.ceil(((b - a)**5 * M / (180 * tolerance))**(1/4))
    return n
```

Для заданной точности $\varepsilon = 10^{-3}$ получаем:
```
Для метода парабол n=4
```
