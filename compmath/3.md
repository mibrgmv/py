# Отчет по численным методам решения нелинейных уравнений

## 1. Введение

В данном отчете рассматриваются численные методы решения нелинейных уравнений на примере уравнения:

$$2\ln(x+1) - \frac{1}{x} = 0$$

Для решения данного уравнения используются следующие методы:
- Метод половинного деления (дихотомии)
- Комбинированный метод
- Метод простых итераций

Каждый из методов будет рассмотрен с математической точки зрения, включая основные формулы, алгоритмы, а также особенности сходимости.

## 3. Предварительный анализ

Исследуем функцию $f(x) = 2\ln(x+1) - \frac{1}{x}$.

Область определения функции: $x \in \mathbb{R} \setminus \{0\}$ и $x > -1$, то есть $x \in (-1, 0) \cup (0, +\infty)$.

Асимптотическое поведение:
- При $x \to 0^+$: $\ln(x+1) \to 0$, но $\frac{1}{x} \to +\infty$, поэтому $f(x) \to -\infty$
- При $x \to +\infty$: $\ln(x+1) \sim \ln(x)$, а $\frac{1}{x} \to 0$, поэтому $f(x) \to +\infty$

Поскольку функция непрерывна на интервале $(0, +\infty)$ и принимает на концах этого интервала значения разных знаков, по теореме о промежуточном значении на этом интервале существует хотя бы один корень уравнения.

## 5. Метод половинного деления (дихотомии)

### 5.1. Описание метода

Метод половинного деления основан на теореме о промежуточном значении и применяется к непрерывной функции на отрезке $[a, b]$, где $f(a) \cdot f(b) < 0$.

### 5.2. Алгоритм

1. Находим середину отрезка $c = \frac{a + b}{2}$
2. Вычисляем $f(c)$
3. Если $|f(c)| < \varepsilon$ (где $\varepsilon$ - заданная точность) или $\frac{b - a}{2} < \varepsilon$, то $c$ - приближенное значение корня
4. Иначе, если $f(a) \cdot f(c) < 0$, то корень находится на $[a, c]$ и полагаем $b = c$
5. Если же $f(c) \cdot f(b) < 0$, то корень находится на $[c, b]$ и полагаем $a = c$
6. Повторяем процесс с пункта 1 до достижения заданной точности

### 5.3. Математическая формализация

На каждой итерации:
$$c_k = \frac{a_k + b_k}{2}$$

Если $f(a_k) \cdot f(c_k) < 0$, то:
$$a_{k+1} = a_k, b_{k+1} = c_k$$

Если $f(c_k) \cdot f(b_k) < 0$, то:
$$a_{k+1} = c_k, b_{k+1} = b_k$$

Критерий останова:
$$|b_k - a_k| < 2\varepsilon \text{ или } |f(c_k)| < \varepsilon$$

### 5.4. Скорость сходимости

Метод половинного деления имеет линейную скорость сходимости. На каждом шаге длина отрезка, содержащего корень, уменьшается вдвое:
$$|b_{k+1} - a_{k+1}| = \frac{|b_k - a_k|}{2}$$

Для достижения точности $\varepsilon$ требуется примерно $\log_2\frac{b-a}{\varepsilon}$ итераций.

## 6. Комбинированный метод
### 6.1. Алгоритм
1. Начинаем с отрезка [a, b], содержащего корень уравнения f(x) = 0, где f(a)·f(b) < 0
2. На каждом шаге:
   - Пытаемся применить метод Ньютона: $x_{newton} = x - \frac{f(x)}{f'(x)}$
   - Если производная близка к нулю или метод Ньютона выходит за границы [a, b], используем метод секущих
   - При применении метода секущих учитываем знак f'(x) для обеспечения сходимости с нужной стороны
   - Сужаем интервал [a, b] на основе знака f(x) в новой точке для гарантированного заключения корня
3. Повторяем, пока не будет достигнута заданная точность $|x_{k+1} - x_k| < \varepsilon$

### 6.2. Математическая формализация
В комбинированном методе используются различные подходы в зависимости от поведения функции:

- Метод Ньютона: $x_{newton} = x - \frac{f(x)}{f'(x)}$
- При f'(x) > 0 и f(x) > 0 (или f'(x) < 0 и f(x) < 0) метод Ньютона даёт приближение справа
- При f'(x) > 0 и f(x) < 0 (или f'(x) < 0 и f(x) > 0) метод Ньютона даёт приближение слева

- Метод секущих: $x_{next} = x - f(x) \cdot \frac{b - a}{f(b) - f(a)}$
- Обеспечивает сходимость с противоположной стороны от метода Ньютона, что повышает устойчивость алгоритма

### 6.3. Особенности реализации
- Алгоритм автоматически переключается между методами для обеспечения сходимости с разных сторон от корня
- Метод сохраняет отрезок [a, b], содержащий корень, что гарантирует надёжность
- Для точки x методы секущей и хорды обеспечивают приближения с противоположных сторон в зависимости от знаков f(x) и f'(x)
- Начальное приближение выбирается как середина отрезка [a, b]

### 6.4. Скорость сходимости
- Метод Ньютона обеспечивает квадратичную сходимость вблизи корня при выполнении соответствующих условий
- Метод секущих обеспечивает сверхлинейную сходимость порядка примерно 1.618
- Комбинирование методов, сходящихся с разных сторон, повышает устойчивость и надёжность решения

## 7. Метод простых итераций

### 7.1. Описание метода

Метод простых итераций основан на преобразовании исходного уравнения $f(x) = 0$ к виду $x = \varphi(x)$, где $\varphi(x)$ - некоторая функция, называемая итерационной.

Для нашего уравнения $2\ln(x+1) - \frac{1}{x} = 0$ преобразование выглядит следующим образом:
$$2\ln(x+1) = \frac{1}{x}$$
$$x = \frac{1}{2\ln(x+1)}$$

Таким образом, итерационная функция $\varphi(x) = \frac{1}{2\ln(x+1)}$.

### 7.2. Алгоритм

1. Выбираем начальное приближение $x_0$
2. Вычисляем последовательность приближений по формуле:
   $$x_{k+1} = \varphi(x_k)$$
3. Продолжаем итерации, пока не будет достигнута заданная точность $|x_{k+1} - x_k| < \varepsilon$

### 7.3. Математическая формализация

Итерационная формула метода простых итераций:
$$x_{k+1} = \varphi(x_k) = \frac{1}{2\ln(x_k+1)}$$

Критерий останова:
$$|x_{k+1} - x_k| < \varepsilon$$

### 7.4. Условия сходимости

Метод простых итераций сходится, если выполнено условие:
$$|\varphi'(x)| < 1 \text{ в окрестности корня}$$

Для нашего случая:
$$\varphi'(x) = \frac{d}{dx}\left(\frac{1}{2\ln(x+1)}\right) = -\frac{1}{2(x+1)(\ln(x+1))^2}$$

Если $|\varphi'(x)| < 1$ в окрестности корня, то метод сходится.


## 8. Анализ результатов

Согласно результатам работы программы, найден один корень уравнения на интервале $[0.81, 0.91]$. Рассмотрим пошаговые вычисления для каждого метода.

### 8.1. Метод половинного деления

Для интервала $[a_0, b_0] = [0.81, 0.91]$ выполним несколько итераций:

**Итерация 1:**
- $c_1 = \frac{a_0 + b_0}{2} = \frac{0.81 + 0.91}{2} = 0.86$
- $f(a_0) = 2\ln(0.81+1) - \frac{1}{0.81} \approx -0.02718$
- $f(c_1) = 2\ln(0.86+1) - \frac{1}{0.86} \approx 0.03339$
- $f(a_0) \cdot f(c_1) < 0$, поэтому $[a_1, b_1] = [0.81, 0.86]$

**Итерация 2:**
- $c_2 = \frac{a_1 + b_1}{2} = \frac{0.81 + 0.86}{2} = 0.835$
- $f(a_1) = f(a_0) \approx -0.02718$
- $f(c_2) = 2\ln(0.835+1) - \frac{1}{0.835} \approx 0.00250$
- $f(a_1) \cdot f(c_2) < 0$, поэтому $[a_2, b_2] = [0.81, 0.835]$

**Итерация 3:**
- $c_3 = \frac{a_2 + b_2}{2} = \frac{0.81 + 0.835}{2} = 0.8225$
- $f(a_2) = f(a_0) \approx -0.02718$
- $f(c_3) = 2\ln(0.8225+1) - \frac{1}{0.8225} \approx -0.01257$
- $f(a_2) \cdot f(c_3) > 0$, поэтому $[a_3, b_3] = [0.8225, 0.835]$

Процесс продолжается до достижения заданной точности $\varepsilon = 10^{-5}$. После 13 итераций получаем:
- Найденный корень: $x \approx 0.8285$
- Значение функции: $f(x) \approx -9.309 \cdot 10^{-6}$
- Общее количество итераций: 13

### 8.2. Комбинированный метод (метод секущих)

Начнем с интервала $[x_0, x_1] = [0.81, 0.91]$ и выполним несколько итераций:

**Итерация 1:**
- $f(x_0) = f(0.81) \approx -0.02718$
- $f(x_1) = f(0.91) \approx 0.09012$
- $x_2 = x_1 - f(x_1) \cdot \frac{x_1 - x_0}{f(x_1) - f(x_0)} = 0.91 - 0.09012 \cdot \frac{0.91 - 0.81}{0.09012 - (-0.02718)} \approx 0.8389$

**Итерация 2:**
- $f(x_1) = f(0.91) \approx 0.09012$
- $f(x_2) = f(0.8389) \approx 0.00933$
- $x_3 = x_2 - f(x_2) \cdot \frac{x_2 - x_1}{f(x_2) - f(x_1)} = 0.8389 - 0.00933 \cdot \frac{0.8389 - 0.91}{0.00933 - 0.09012} \approx 0.8301$

- **Итерация 3:**
- $f(x_2) = f(0.8389) \approx 0.00933$
- $f(x_3) = f(0.8301) \approx 0.00153$
- $x_4 = x_3 - f(x_3) \cdot \frac{x_3 - x_2}{f(x_3) - f(x_2)} = 0.8301 - 0.00153 \cdot \frac{0.8301 - 0.8389}{0.00153 - 0.00933} \approx 0.8285$

После 4 итераций получаем:
- Найденный корень: $x \approx 0.8285$
- Значение функции: $f(x) \approx 1.175 \cdot 10^{-11}$
- Общее количество итераций: 4

### 8.3. Метод простых итераций

Для метода простых итераций мы используем функцию $\varphi(x) = \frac{1}{2\ln(x+1)}$. Начнем с точки $x_0 = \frac{0.81 + 0.91}{2} = 0.86$ и выполним несколько итераций:

**Итерация 1:**
- $x_1 = \varphi(x_0) = \varphi(0.86) = \frac{1}{2\ln(0.86+1)} \approx 0.8169$

**Итерация 2:**
- $x_2 = \varphi(x_1) = \varphi(0.8169) = \frac{1}{2\ln(0.8169+1)} \approx 0.8343$

**Итерация 3:**
- $x_3 = \varphi(x_2) = \varphi(0.8343) = \frac{1}{2\ln(0.8343+1)} \approx 0.8244$

**Итерация 4:**
- $x_4 = \varphi(x_3) = \varphi(0.8244) = \frac{1}{2\ln(0.8244+1)} \approx 0.8303$

**Итерация 5:**
- $x_5 = \varphi(x_4) = \varphi(0.8303) = \frac{1}{2\ln(0.8303+1)} \approx 0.8271$

Метод продолжает осциллировать, медленно приближаясь к корню. После 30 итераций получаем:
- Найденный корень: $x \approx 0.8285$
- Значение функции: $f(x) \approx -1.089 \cdot 10^{-5}$
- Общее количество итераций: 30

### 8.4. Сравнение методов

1. **Точность**: Комбинированный метод (метод секущих) дал наиболее точный результат с минимальным значением функции.

2. **Эффективность**: Комбинированный метод также оказался наиболее эффективным, потребовав всего 4 итерации для достижения высокой точности.

3. **Скорость сходимости**: Методы можно расположить по убыванию скорости сходимости:
   - Комбинированный метод (метод секущих)
   - Метод половинного деления
   - Метод простых итераций

## 9. Заключение

В ходе исследования было рассмотрено решение нелинейного уравнения $2\ln(x+1) - \frac{1}{x} = 0$ тремя различными методами.

Установлено, что для данного уравнения существует корень $x \approx 0.8285$. Наиболее эффективным для нахождения этого корня оказался комбинированный метод (метод секущих), который потребовал минимального количества итераций и обеспечил наибольшую точность.

Метод простых итераций, несмотря на свою простоту, оказался наименее эффективным, что объясняется низкой скоростью его сходимости для данного уравнения.

Метод половинного деления, хотя и не самый быстрый, обладает надежностью и гарантированно сходится к корню при правильном выборе начального интервала, содержащего корень.
