# Теоретическое обоснование

Метод Ньютона для системы нелинейных уравнений использует следующую итерационную формулу:

$$X^{(n+1)} = X^{(n)} - [J(X^{(n)})]^{-1} \cdot F(X^{(n)})$$

где:

- $\mathbf{X}^{(n)} = \begin{pmatrix} x_1^{(n)} \\ x_2^{(n)} \end{pmatrix}$ - вектор неизвестных на n-й итерации
- $\mathbf{F}(\mathbf{X}) = \begin{pmatrix} f_1(x_1, x_2) \\ f_2(x_1, x_2) \end{pmatrix}$ - вектор-функция
- $J(X)$ - матрица Якоби частных производных:

$$J(X) = \begin{pmatrix} 
\frac{\partial f_1}{\partial x_1} & \frac{\partial f_1}{\partial x_2} \\
\frac{\partial f_2}{\partial x_1} & \frac{\partial f_2}{\partial x_2}
\end{pmatrix}$$

## 3. Метод простых итераций

### Теоретическое обоснование

Для метода простых итераций систему нужно привести к виду:

$$\begin{cases}
x_1 = \phi_1(x_1, x_2) \\
x_2 = \phi_2(x_1, x_2)
\end{cases}$$

При этом должно выполняться условие сходимости: максимальная по модулю сумма частных производных функций $\phi_1$ и $\phi_2$ меньше единицы.

### Реализация метода простых итераций

Преобразуем исходную систему:

$$\begin{cases}
x_1 = -\cos(x_2 - 2) \\
x_2 = \sin(x_1 + 0.5) - 1.2
\end{cases}$$

Итерационная формула:

$$\begin{cases}
x_1^{(n+1)} = -\cos(x_2^{(n)} - 2) \\
x_2^{(n+1)} = \sin(x_1^{(n)} + 0.5) - 1.2
\end{cases}$$

Используем то же начальное приближение $\mathbf{X}^{(0)} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$
